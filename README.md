# Java-Learning
This repository is my learning journey of Java. It includes notes, code examples, and projects that demonstrate the concepts of Java in real-world scenarios.

## What is the Structure
The repository consists of files and directories that focus on specific topics and concepts:
* **[Fundamentals_of_Java](./Fundamentals_of_Java):** Introduction to **Java** Programming fundamentals including conditionals, iterations and functions, etc.
* **[Arrays_&_Strings_in_Java](./Arrays_&_Strings_in_Java):** Working with Arrays & Strings in **Java** along with their methods and also discussed their performances.
* **[Object_Oriented_Programming_with_Java](./Object_Oriented_Programming_with_Java):** Understanding Object-Oriented Programming in **Java** in deep it consists objects, classes and other OOPs concepts along with Collection Framework, Interfaces, Lambda Functions and Vector Classes, etc. 
* **[Java_Architecture.jpeg](./Java_Architecture.jpeg):** It is a pictorial view of Architecture of **Java** which explains the working of **Java**.
* **[Java_Architecture.md](./Java_Architecture.md):** It is a diagrammatic view of Architecture of **Java** which explains the working of **Java**.
* **[JVM_Execution.txt](./Java_Execution.txt):** It is a diagrammatic view of Execution of **JVM** which explains the working of **JVM**.
* **[JVM_Execution.jpeg](./JVM_Execution.jpeg):** It is a pictorial view of Execution of **JVM** which explains the working of **JVM**.

<br>
Each folder or directory contains:
<br>

* **Notes:** Summaries and explanations of code as comments.
* **Code Examples:** Practical code snippets demonstrating the discussed topics.
* **Exercises:** Solutions to exercises to reinforce learning.


## Which Technologies are used
* **JDK**: Software development environment that includes essential tools and libraries for creating Java applications.

## How to Getting Started
### Setup Application
1. **Clone this repository:**
   ```bash
   git clone https://github.com/thebraudalf/Java-Learning.git
   ```

2. **Open specific Directory:** Navigate to a specific folder or directory (e.g., Fundamentals_of_Java):
   ```bash
   cd Java-Learning\Fundamentals_of_Java
   ```

3. **Run the Code:** Go to a specific file (e.g., introduction.java) in your terminal and Run.
   ```bash
   java introduction.java
   ```
